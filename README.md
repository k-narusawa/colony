# 荒廃コロニー(PWA プロトタイプ)

電力と人手をやりくりする放置コロニー育成の検証用プロトタイプ。

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体。パラメータは冒頭の `C` と `UPS` に集約 |
| `balance-check.js` | バランス確認用のヘッドレスシム。`C` をいじったら `node balance-check.js` |
| `offline-check.js` | 留守にしたぶんの計算を確かめる。`node offline-check.js` |
| `manifest.json` | ホーム画面に追加するための設定 |
| `sw.js` | オフライン起動用。更新時は `CACHE` の数字を上げる |
| `assets/tiles.png` | 俯瞰図の絵。Kenney「Sci-Fi RTS」(CC0)。この1枚に地形も建物も住民も入っている |
| `docs/asset-plan.md` | タイルの座標と、盤面の決めごと。絵を差し替える前に読むこと |
| `icon-*.png` | アイコン。`icon.py` で再生成できる |

## 公開手順(GitHub Pages)

1. リポジトリを作り、このフォルダの中身をルートに置く
2. Settings → Pages → Source を `main` ブランチのルートに設定
3. 数分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

HTTPS が必要なので、ローカルの `file://` では Service Worker が動かない。
手元で試すなら `python3 -m http.server` で `http://localhost:8000` を使う。

## iPhone のホーム画面に入れる

1. **Safari で**開く(Chrome では追加できない)
2. 共有ボタン → 「ホーム画面に追加」
3. アイコンから起動するとアドレスバーが消えて全画面になる

通知とバッジは、ホーム画面に追加した状態でだけ使える。まだ実装していない。

## セーブと、留守にしていたあいだの進行

コロニーは `localStorage` の `colony-save` に丸ごと入る。10秒ごとと、画面を離れたときに保存する。

戻ってきたぶんは、保存した実時刻との差を1秒刻みで本編の `step()` に流し込む。
別式を持つと本編とズレるので、計算はひとつしかない。上限は `C.offlineCap`(8時間)。
留守のあいだだけ突発事象を止めてある — 手を出せない事故で発電機を焼かれると理不尽になるため。

貯まる量に別の上限は置いていない。掘れる場所(手元の廃墟と、道が届いた鉱床)が尽きれば
スクラップが止まり、食料は `foodCap`(農場を強化すると `foodCapPerLv` ぶん伸びる)で
頭打ちになるので、そこが自然な天井になる。

## 鉱床と道

スクラップの供給源は2段構え。手元の廃墟(初期 1000)は最初から掘れるが、
それを掘り尽くしたら、マップにランダムで湧く鉱床へ道を繋がないと先が無い。
HUD の「道を敷く」を押してから盤面をタップすると、スクラップ 10 で1マス予約でき、
待機中の住民が歩いて行って 15 秒で敷く(予約の再タップで取り消し・返金)。
道はコロニーか既設の道に接するマスにしか置けないので、敷けた道は必ず繋がっている —
接続判定はこの配置ルールだけで済ませていて、経路探索は持っていない。
突発事象の「新しい廃墟」も、埋蔵量への直接加算から「鉱床がマップに湧く」に変わった。

時間の単位は「日」。昼夜ひと回り(`dayLen + nightLen` = 120秒)で1日進む。
記録の時刻も `[3日目 夜]` の形で、`stamp()` が `S.t` から出している。

やり直すときは HUD 右端の「やり直す」を2回押す。1回目で赤くなり、5秒以内の2回目で消える。
`confirm()` は PWA でループを止めるので使っていない。消すだけでは駄目で、
リロードで走る `pagehide` の保存が書き戻すため、`wipe()` は保存自体を止めてからリロードする。

## 実機で確かめること

- 「＋」「−」が指で押しやすいか(スマホ幅では 52×48px に拡大済み)
- 忙しいときにスクロールが必要になっていないか
- 俯瞰図のドット絵が潰れずに読めるか(潰れるなら盤面をさらに狭くする)
- 盤面と下のパネル、どちらを見て操作しているか
- 発電機が故障した瞬間に迷いが生まれるか
- 日没の予告を見てから手が動くか(予告は 25 秒前、着任は 20 秒。ここが噛み合っているか)
- 農場を強化したとき、電力を食い合うことに気づけるか(収穫 +0.8/秒 と引き換えに +1.5kW。
  発電機が追いついていないと工房が先に落ちる)
- 一晩あけて開いたとき、要約の1行を読んで状況が掴めるか
- 盤面のドラッグ移動・ピンチ拡縮が指で自然に効くか
- 「道を敷く」を押してからのタップで、狙ったマスに置けるか(パンと誤爆しないか)

## 決めきれていないこと

- **留守のぶんはまだ大きめ。** 初期埋蔵量を 1000 に絞ったので、8時間空けても部品 500 で
  頭打ちになる(以前は 1500)。先へ進むには帰ってきて道を敷く必要があるが、
  道さえ繋がっていれば留守中も鉱床を掘り続けるので、繋ぎすぎると同じ問題が戻ってくる
- 終わりが無くなったので、何を目指す遊びなのかが未定。強化を買い切ったあと何も起きない
- 鉱床の量と湧く頻度は仮置き(初期3つ 800〜1600、事象で 1200)。道の費用 10 も未検証
- 留守にしても保つ配置を組ませたいのか、帰ってきたら建て直させたいのか
