# 荒廃コロニー(PWA プロトタイプ)

電力と人手をやりくりする放置コロニー育成の検証用プロトタイプ。

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体。パラメータは冒頭の `C` と `UPS` に集約 |
| `balance-check.js` | バランス確認用のヘッドレスシム。`C` をいじったら `node balance-check.js` |
| `manifest.json` | ホーム画面に追加するための設定 |
| `sw.js` | オフライン起動用。更新時は `CACHE` の数字を上げる |
| `icon-*.png` | アイコン。`icon.py` で再生成できる |

## 公開手順(GitHub Pages)

1. リポジトリを作り、このフォルダの中身をルートに置く
2. Settings → Pages → Source を `main` ブランチのルートに設定
3. 数分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

HTTPS が必要なので、ローカルの `file://` では Service Worker が動かない。
手元で試すなら `python3 -m http.server` で `http://localhost:8000` を使う。

## iPhone のホーム画面に入れる

1. **Safari で**開く(Chrome では追加できない)
2. 共有ボタン → 「ホーム画面に追加」
3. アイコンから起動するとアドレスバーが消えて全画面になる

通知とバッジは、ホーム画面に追加した状態でだけ使える。まだ実装していない。

## 実機で確かめること

- 「＋」「−」が指で押しやすいか(スマホ幅では 52×48px に拡大済み)
- 忙しいときにスクロールが必要になっていないか
- 発電機が故障した瞬間に迷いが生まれるか

## まだ無いもの

- セーブ(状態は `S` に集約してあるので、まるごと保存すれば足りる)
- オフライン進行(離脱時刻と復帰時刻の差分で計算する。フレーム数で数えないこと)
- 通知、バッジ
