# アセット導入メモ

`index.html` を絵のある画面にするための決定事項。作業中に見失いやすい前提だけ残す。

## 素材

- Kenney「Sci-Fi RTS」より `assets/tiles.png`(@2版、2304×896)**1枚だけ**。
  地形・建物・ユニット・岩がすべてこの1枚に入っている。個別PNGもスプライトシートも要らない。
- CC0(`assets/KENNEY-LICENSE.txt`)。帰属不要・再配布可なので、公開リポジトリに置いて問題ない。
  itch.io や FreePixel の素材は「生ファイルの再配布」を禁じているため使えない。ここは戻さないこと。

## タイルシートの座標

18列 × 7行、1タイル 128px。`[行, 列]` で参照する。

| 用途 | 座標 |
|---|---|
| 地面(赤茶のベタ) | `[0,0]` `[0,1]` |
| 地面(岩肌の模様つき) | `[0,4]`〜`[2,8]` |
| 発電機 | `[1,14]` 縦フィンにオレンジのライン |
| 解体場 | `[1,15]` かまぼこ型の格納庫 |
| 工房 | `[2,15]` 横長の建屋 |
| 水耕農場 | `[2,17]` 青い水タンク2本 |
| 廃墟(埋蔵量) | `[5,2]`〜`[5,5]` 灰色の岩。赤い岩(4行目)は地面と同系色で沈む |
| 地面の小石 | `[5,0]` `[4,0]` |
| 住民・整備 | `[3,8]` 青 |
| 住民・解体 | `[4,8]` 赤 |
| 住民・工作 | `[5,8]` 緑 |

建物の見分けは形で付けている(縦フィン/ドーム/横長/青タンク)。似た灰色の建物に差し替えると
区別できなくなるので、変えるなら形の違うものを選ぶこと。

## 盤面

- `<canvas>` 1枚。論理 8×5 タイル、1タイル 64 論理px(512×320)を CSS で 1.5 倍まで引き伸ばす。
  ソースは 128px なので `drawImage` で半分に縮め、`devicePixelRatio` でバックバッファを上げる。
  DPR=2 の端末ではこれで素材が等倍になる。
  盤面を広げると建物が小さく散って見えるので、8×5 より大きくしないこと。
- 建物の位置は**固定**。プレイヤーは配置しない。可変にすると配置ルールが要りスコープが倍になる。
- 着任中の住民は `w.eta` を 0→1 に正規化して座標を補間する。**新しい状態は増やさない**。
- 盤面に立つ人型は**待機中と着任中だけ**。持ち場にいる人は描かず、建物の下に `3/5` を出す。
  人を並べると頭数を数える手間が要り、枠がいくつ空いているかも読めなかった。
  数字の色は 空=赤 / 満員=青 / それ以外=白。水耕農場は人手不要なので出さない。
