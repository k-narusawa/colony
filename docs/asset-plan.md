# アセット導入メモ

`index.html` を絵のある画面にするための決定事項。作業中に見失いやすい前提だけ残す。

## 素材

- Kenney「Sci-Fi RTS」より `assets/tiles.png`(@2版、2304×896)。建物・増築・岩・住民はすべてこの1枚。
- CC0(`assets/KENNEY-LICENSE.txt`)。帰属不要・再配布可なので、公開リポジトリに置いて問題ない。
  itch.io や FreePixel の素材は「生ファイルの再配布」を禁じているため使えない。ここは戻さないこと。
- 地面だけ LudicArts「Free Desert Top-Down Tileset」(CC-BY 3.0、`assets/LUDICARTS-LICENSE.txt`)の
  `assets/ground.png`(384×128、128px 角 3 枚)。原画は黄色い砂なので `-modulate 85,80,88` で赤茶に寄せ、
  256px から半分に縮めてある。`[0,0]` 無地の地面、`[0,1]` 小石、`[0,2]` 枯れ草。
  CC-BY なので README に帰属を書いてある。消さないこと。

## 盤面

- **地面は `createPattern` の1回塗り。** マスごとに `drawImage` すると倍率が端数のとき境目に
  1px の線が出る(Kenney のベタ塗りでは見えなかった)。無地は1枚だけで、回転・反転で変化を付けると
  継ぎ目や鏡像の模様が出るので使わない。変化は小石と枯れ草を 1/7 のマスに散らして付けている。
- **建物・岩・住民には落ち影を付ける(`sprite()`)。** canvas の `shadow*` は絵の透明部分に出ないので
  輪郭どおりの影になる。影のずれ幅と暈しは変換行列の影響を受けないため `M.sc` を掛けている。
  影を付けたくない描画(移設の予定地など)は `blit()` を直接呼ぶ。

- `<canvas>` 1枚。世界は 24×16 タイル、1タイル 64 論理px。表示枠は `aspect-ratio:8/5` で固定し、
  中はカメラ(`cam` = 左上の世界座標と倍率)で動かす。1本指ドラッグでパン、2本指でピンチズーム、
  PC はホイール。ズームは世界がちょうど収まる倍率〜2倍。バックバッファは表示枠×DPR ぶんだけ持つ。
  ソースは 128px なので `drawImage` で半分に縮め、DPR=2 の端末で等倍になるのは従来どおり。
- かつて「8×5 より大きくしないこと」としていたが、道を敷いて離れた鉱床を掘るゲーム性を
  入れるために広げた。「建物が小さく散って見える」問題はカメラで寄れるので解消している。
- コロニー区画は従来の 8×5 のまま、世界の `(8,5)` を原点に置く(`BASE`)。
  `SITE` / `ANNEX` / `RUBBLE` / `IDLE_Y` は**コロニー内座標のまま**で、描画時に
  `g.translate` でずらしている。世界座標に書き直さないこと。
  鉱床(`S.ores`)と道(`S.roads`)は世界座標で、translate の**前**に描く。
- **道はタイル絵ではなく canvas の帯で描く。** シートの小道タイル(`[0,4]`〜`[2,8]`)は
  装飾用の一枚絵で、絵柄の出入口位置がマスごとにバラバラなため、隣り合わせても繋がらない。
  マスの中心から、接続している辺の中点へ太い線を2層(暗い縁+舗装色)引くと、
  隣のマスと必ず届く。予約中のマスは同じ絵を半透明で出す。
- 鉱床は廃墟と同じ灰色の岩(`[5,2]`〜`[5,5]`)を流用し、残量が多いほど大きな岩にする。
  掘り尽くすと消える。
- 建物の位置は**固定**。プレイヤーは配置しない。可変にすると配置ルールが要りスコープが倍になる。
- **レベルアップの見た目は「増築」で出す。**本体のタイルは変えない。同じ建物の Lv2 版という絵は
  素材に無いので、差し替えると別の建物になってしまい「形で見分ける」が壊れる。
  代わりに Lv が上がるごとに、決まったマスへ小物を1つ足す(`ANNEX`)。Lv3 で打ち止め。
  置き場も固定で、**人手を持つ建物の真下は空ける**。そこには `3/5` の表示が乗るため。
  発電機は左(`(0,0)` `(0,1)`)、解体場は左下(`(0,2)` `(0,3)`)、工房は右(`(4,2)` `(5,2)`)、
  居住区だけ表示が無いので真下(`(2,1)` `(2,2)`)に伸ばす。
- 居住区は `(2,0)`。人手を持たないので `ORDER` には入れない(`B` にも無く、`3/5` も出ない)。
  盤面に描くものは `DRAW`(= `ORDER` + 居住区)で回す。ここを混ぜると人数の勘定が壊れる。
- 着任中の住民は `w.eta` を 0→1 に正規化して座標を補間する。**新しい状態は増やさない**。
- 盤面に立つ人型は**待機中と着任中だけ**。持ち場にいる人は描かず、建物の下に `3/5` を出す。
  人を並べると頭数を数える手間が要り、枠がいくつ空いているかも読めなかった。
  数字の色は 空=赤 / 満員=青 / それ以外=白。水耕農場は人手不要なので出さない。

唯一の写実寄りは LudicArts「Free Desert Top-Down Tileset」(CC-BY 3.0、256px)だが地面と小物だけ。
https://opengameart.org/content/free-desert-top-down-tileset
